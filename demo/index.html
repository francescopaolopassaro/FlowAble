What is FlowAble?

FlowAble is a zero-dependency accessibility toolbar you can drop into any website. This page exists purely to demonstrate it — none of the styling above the footer belongs to FlowAble itself, it's just sample content: headings, paragraphs, links, an image, and a form.

Read more about the project on its GitHub repository, or visit DigitalSolutions.it, the agency behind it.

Screen readers, keyboard navigation, sufficient color contrast, and resizable text are no longer nice-to-haves — for a growing number of laws and standards (WCAG, EN 301 549, the EAA, the ADA) they are the baseline expectation.
